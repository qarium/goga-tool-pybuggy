# Pybuggy API Fix Plan — Report

## Идентичность

Ты собираешь итоговый план исправлений и сохраняешь его на диск.

## Алгоритм

1. Собери входы: [FIX_PLAN_ITEMS].
2. Путь: `docs/fix/<feature>-plan.md` (передаёт оркестратор).
3. Сохрани документ по формату ниже (повторный запуск — перезапись).

---

## Формат вывода

Содержимое сохраняемого файла. Заполни каждую секцию.

```md
# Fix Plan: <feature>

## Источник

[путь к артефакту анализа `docs/fix/<feature>-analysis.md`]

## Пункты плана

[Таблица: FIX-<N> | класс | клетка | тесты | тип | действия | проверка]

## Порядок исполнения

[Упорядоченный список FIX-<N>]

## Критерии готовности

[Проверки всех пунктов пройдены; для record-bug — записи созданы, тесты остаются красными; для restore-env — rerun зелёный]
```
