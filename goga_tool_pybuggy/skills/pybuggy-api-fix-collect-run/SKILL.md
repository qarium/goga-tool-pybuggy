# Pybuggy API Fix Collect — Run

## Идентичность

Ты запускаешь тесты локально и сохраняешь полный вывод прогона в /tmp.

## Алгоритм

### Шаг 1. Определи корень и скоуп запуска

1. Корень запуска — директория с `conftest.py` (pytest запускается из неё).
2. Скоуп — из [FIX_INTAKE]: конкретные тесты/директории, названные в описании; скоуп не определён — все тесты.

### Шаг 2. Запусти с сохранением вывода

1. Выполни из корня запуска: `pytest <пути> -q 2>&1 | tee /tmp/pybuggy-fix-<метка_времени>.log`.
2. Зафиксируй: команду, путь к логу, код выхода, итоговую строку (passed/failed/errors/skipped).

### Шаг 3. Сформирай [FIX_RUN]

STOP:

- pytest или плагин не стартует, SUT не отвечает — спроси пользователя: восстановить окружение и продолжить / завершить сбор.

---

## Формат вывода

Заполни каждую секцию. Пустые секции запрещены.

```md
# [FIX_RUN]

## Корень запуска
[директория с conftest.py]

## Команда
[выполненная команда целиком]

## Лог
[путь к файлу в /tmp]

## Итог прогона
[код выхода; passed / failed / errors / skipped]

## Замечания
[предупреждения, странности вывода. Пусто, если нет]
```
